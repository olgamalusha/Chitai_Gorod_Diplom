
# Автоматизация тестирования «Читай-город»

Дипломный проект по автоматизации UI- и API-тестирования
интернет-магазина https://www.chitai-gorod.ru/

## Технологии

- Python
- pytest
- Selenium WebDriver
- requests
- Allure Report

## Покрываемый функционал

### UI-тесты
1. Поиск книг по названию.
2. Поиск книг по автору.
3. Переход в категорию художественной литературы.
4. Фильтрация книг по цене.
5. Добавление книги в корзину.

### API-тесты
1. Получение фильтров поиска.
2. Поисковые подсказки по названию книги.
3. Поисковые подсказки по автору.
4. Поиск без авторизации.
5. Поиск с невалидным токеном.

## Установка

Создать виртуальное окружение:

```powershell
python -m venv .venv
```

Активировать его в Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установить зависимости:

```powershell
python -m pip install -r requirements.txt
```

Для UI-тестов необходим установленный Google Chrome.

## Запуск тестов

Все тесты:

```powershell
python -m pytest tests/ -v
```

Только UI-тесты:

```powershell
python -m pytest -m ui -v
```

Только API-тесты:

```powershell
python -m pytest -m api -v
```

## Отчёт Allure

Для формирования результатов:

```powershell
python -m pytest tests/ -v --alluredir=allure-results --clean-alluredir
```

Для просмотра отчёта требуется отдельно установленный
Allure Commandline.

```powershell
allure serve allure-results
```

## Известное несоответствие

UI-04 обнаруживает книгу «Кровь и попкорн» стоимостью
449 ₽ при установленном диапазоне фильтрации 500–1000 ₽.

Несоответствие воспроизведено вручную и зафиксировано
в баг-репорте. Поскольку официальные требования к алгоритму
фильтрации отсутствуют, дефект считается предполагаемым
до уточнения бизнес-логики.
